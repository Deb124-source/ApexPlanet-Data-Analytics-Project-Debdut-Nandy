# ApexPlanet Data Analytics Internship

This repository contains my work completed during the 30-Day Data Analytics Internship at ApexPlanet.

The internship focuses on developing practical skills in data analytics, including data cleaning, exploratory data analysis, SQL, data visualization, dashboards, statistical analysis, and basic predictive analytics.

## Internship Tasks

- Task 1 — Foundation & Exploratory Data Analysis
- Task 2 — SQL for Data Extraction
- Task 3 — Data Visualization & Dashboarding
- Task 4 — Advanced Analytics (Basic)
- Task 5 — Final Report, Automation & Presentation

---

## Task 1 — Foundation & Exploratory Data Analysis

Task 1 focused on preparing and exploring an E-Commerce Sales dataset.

### Work Completed

- Dataset loading and inspection
- Handling missing values
- Removing duplicate records
- Correcting data types
- Handling invalid values
- Identifying and handling outliers using the IQR method
- Creating a `SalesAmount` feature
- Statistical summary
- Univariate analysis using histograms and boxplots
- Product and country-level sales analysis
- Monthly order trend analysis
- Correlation analysis
- Customer-level sales analysis
- Documentation of key findings

### Task 1 Files

- `data/online_retail_cleaned.zip`
- `notebooks/Task_1_EDA.ipynb`

---

## Task 2 — SQL for Data Extraction

Task 2 focused on using SQL to extract, analyze, and summarize data from the cleaned E-Commerce Sales dataset.

### Work Completed

- SQL fundamentals
- Data filtering and sorting
- Aggregate functions
- `GROUP BY` and `HAVING`
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- SQL views
- 10 business questions using SQL
- SQLite database integration
- SQLAlchemy integration
- Python and SQL integration using `pandas.read_sql()`
- Reusable SQL utility script

### Task 2 Files

- `notebooks/Task_2_SQL_Analysis.ipynb`
- `sql/Task_2_Queries.sql`
- `scripts/sql_utils.py`
